# Data Sources

Synthetic source-style data for category sourcing analytics, supplier performance, and total-cost-of-ownership modeling.

- `entities.csv`: 36 spend category records.
- `daily_metrics.csv`: 5,040 spend category-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
